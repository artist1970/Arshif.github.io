# ARSHIF · Public Archivist Mentor

ARSHIF is the Verve N Veda archives and preservation guide. **Preserve first. Contextualize carefully.**

## Public front door

This public repository provides a lightweight, static HTML/JavaScript introductory conversation at `index.html`, with:
- 24 source-labelled public archive-navigation Q&As at `knowledge/public-navigation-qa.v1.json`
- Read-only, attributed references to reviewed public Q&A from other mentors
- Visitor-controlled Voice On/Off, browser voice selection, manual replay and stop
- An antique-inspired, accessible VNV/KA page with Cinzel headings, legible controls and official ecosystem navigation
- Existing tools in `tools/`, unchanged by the mentor-front-door release

This is **not** a private archive server, independent large language model, authorized custodial vault, or automated source authentication system. The published orientation Q&As are explanatory public summaries, not citations to private archival originals. Unreviewed research candidates under `knowledge/drafts/` must not enter the public answer bank until authorized editorial review.

## Canonical distinction

- **ARSHIF Public Mentor:** `artist1970/Arshif.github.io` — introduction, conversation and public tool entry
- **ARSHIF Archives:** `vervenveda/Arshif.github.io` — the living archive directory, its public Knowledge Halls, registries and research gateways
- **Private identity:** `artist1970/CORE/ARSHIFCore` — the canonical preservation and source-fidelity charter
- **Auren:** a separate specialist in forensic conversation history and evidence continuity

The source archive and its public hall registry were **not copied, moved or replaced** by this mentor-page upgrade.

## Safety and authorship

ARSHIF keeps original sources distinct from summaries and interpretations. It does not silently modernize historical meaning, invent provenance, reconcile conflicting evidence, retrieve private records, accept credentials or alter user archives. Browser chat does not store conversation transcripts. The optional speech/voice preference is stored in the browser; the static public federation may load existing approved public Q&A files.

## Development and verification

All changes are made on `main`. `tests/arshif-mentor-regression.test.mjs` and the `ARSHIF Public Mentor Regression` workflow cover approved public content boundaries, attribution, user privacy, voice and visual structure. Browser integration still requires desktop and mobile review.
